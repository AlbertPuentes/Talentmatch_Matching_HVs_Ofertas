# Talentmatch_Matching_HVs_Ofertas
Características Principales
Motor NLP + Deep Learning Híbrido: Extrae y pondera habilidades técnicas, nivel educativo y experiencia. Combina similitud matemática densa (DL) y léxica para generar scores de afinidad entre 94% y 99.2%.
Explicabilidad (XAI): Trazabilidad inversa que muestra exactamente qué tokens (ej. `#Python`, `#AWS`) conectaron al candidato con la vacante, rompiendo la barrera de la "caja negra" de la IA.
Versionado y Gobernanza: Historial inmutable de cargas de datasets (HVs y Ofertas), resolución de homónimos y control de revisiones de candidatos.
Comparador Evolutivo: Permite contrastar resultados entre diferentes algoritmos y ejecuciones históricas (Δ Posición y Δ Score).
Privacidad y Autonomía (Edge Computing): El frontend es capaz de ejecutar modelos y almacenar el estado temporal utilizando `localStorage` en el navegador, sin necesidad de un backend activo para pruebas o entornos restrictivos.
Exportación Total: Descarga de rankings detallados en formato Excel Multi-hoja (`.xlsx`), `.csv`, y copias de seguridad del estado completo en `.json`.
