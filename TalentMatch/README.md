# TalentMatch AI · Plataforma de Matching Evolutivo y Versionado (V4 / V4.1 / V4.2)

## Estructura del Paquete Completo
- `index.html`: Aplicación web completa autónoma (NLP TF-IDF + Autoencoder Profundo 256D + Versionado + Exportación Excel/CSV). Reemplaza este archivo con el código HTML proporcionado.

- `.github/workflows/pages.yml` y `.nojekyll`: Despliegue automático en GitHub Pages.
